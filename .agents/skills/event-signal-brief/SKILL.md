# Event Signal Brief

- Read the generated Markdown report and curated JSON.
- Separate verified facts, unverified candidates, conflicts and unavailable fields.
- Include event time with timezone, affected ticker, signal level, score components and source URL.
- State that scores are screening priorities, not probabilities or expected returns.
- Never turn an attention alert into buy/sell advice.
